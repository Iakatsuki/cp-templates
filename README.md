# cp-templates

競技プログラミング（AtCoder 等）で使用するテンプレートおよびライブラリを管理・公開するリポジトリです。

AtCoderの生成AI利用ルール（コンテスト開始前のパブリック公開および提出コードへの参照URL添付）に基づき、事前に作成したコードを公開しています。

---

## 概要 / Overview

* **用途**: 競技プログラミングにおける実装効率化・コード管理
* **ライセンス**: [MIT License](./LICENSE)
* **AIの利用について**: 本リポジトリに含まれる一部のコード・テンプレートは、コンテスト開始前に生成AI（LLM）を用いて作成・整理したものです。
* **公開状態**: コンテスト中の参照および規約順守のため、すべてパブリック（Public）で公開されています。
